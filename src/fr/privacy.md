# {{$frontmatter.title}}

::: info
Afin d'offrir l'ensemble des fonctionnalités, cette extension ne collecte que les données personnelles nécessaires pendant l'utilisation ; voir la déclaration de confidentialité suivante pour plus de détails.
:::

## Quelles données sont collectées ?

| Contenu                      | Utilisation                                                                                                                              | Obligatoire                                               |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Historique de navigation     | Utilisé pour compter le temps de navigation et les visites                                                                               | Oui                                                       |
| Informations sur les onglets | Utilisé pour obtenir automatiquement le nom et l'icône du site Web et améliorer l'expérience utilisateur lors de l'affichage des données | Uniquement si cette fonction est activée dans les options |

## Comment ces données sont-elles utilisées ?

Nous garantissons que toutes les données collectées par cette extension ne seront enregistrées que dans le stockage local de votre navigateur et ne seront jamais transmises ailleurs.

Vous pouvez cependant utiliser les outils fournis par l'extension pour exporter ou importer vos données au format de fichier JSON ou CSV. L'extension vous permet également d'utiliser GitHub Gist ou d'autres services tiers en qui vous avez suffisamment confiance pour sauvegarder vos données.

::: tip
Nous ne faisons que vous aider à collecter des données. Vous en gardez le contrôle total.
:::
