# {{$frontmatter.title}}

Це розширення зберігає ваші дані лише локально за допомогою API `chrome.storage.local`, який надає браузер, і ніколи не надсилає їх нікуди.

Але воно підтримує інструменти, які допомагають передавати ваші дані.

## Експорт та імпорт

Ви можете експортувати дані у файл `.json` на дашборді, а потім імпортувати їх в інших браузерах. Це найзручніше під час переїзду на новий пристрій або в новий браузер.

Також можна імпортувати дані, експортовані з інших схожих розширень, і вирішити, чи перезаписати локальні дані, чи додати до них.

| Інше розширення           | Формат файлу      | Примітка                                   |
| ------------------------- | ----------------- | ------------------------------------------ |
| Webtime Tracker           | `.csv` або `.json`|                                            |
| Web Activity Time Tracker | `.csv`            |                                            |
| History Trends Unlimited  | `.tsc`            | Містить лише дані про кількість візитів     |

## Синхронізація даних між клієнтами

Це розширення не підтримує сервіси, що зберігають дані віддалено.

Натомість воно надає інструменти для синхронізації даних із сторонніми сервісами, яким ви довіряєте.

| Сторонній сервіс    | Передумови                                                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Github Gist         | Токен доступу Github із правами на Gist                                                                                         |
| Obsidian            | Клієнт Obsidian із плагіном [Local REST API for Obsidian](https://github.com/coddingtonbear/obsidian-local-rest-api)            |

Якщо токен налаштовано правильно, ви можете переглядати дані інших клієнтів на сторінці записів.
