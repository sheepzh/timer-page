# {{$frontmatter.title}}

Коли аналітичний звіт вище показав, скільки часу ви витрачаєте на сайти, що забирають його найбільше, можливо, ви захочете контролювати свій час у браузері.

Це розширення дозволяє налаштовувати правила, що обмежують перегляд будь-якого сайту.

## Створення правил обмеження

Спочатку потрібно створити правила на дашборді.

Кожне правило містить кілька частин, як показано в таблиці нижче.

| Частина                  | Опис                                                                                                                       |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| URL обмеження            | URL, який потрібно обмежити. Підтримуються вирази. Наприклад, `https://www.github.com`, `*://www.google.com/**`              |
| Денний ліміт             | Максимальний час на добу, нуль означає без обмежень.                                                                        |
| Ліміт на візит           | Максимальний час на один візит, нуль означає без обмежень.                                                                  |
| Заборонені періоди       | Періоди доби, протягом яких доступ до цільового URL завжди обмежено.                                                        |

## Коли правило спрацьовує

Щойно досягнуто обмежень будь-якого правила, сторінки, які ви переглядаєте, накриваються блокувальним шаром, що унеможливлює перегляд.

Щоб продовжити, потрібно перейти на сторінку правил і вимкнути або змінити це правило. Якщо в налаштуваннях увімкнено розблокування, також потрібна перевірка або пароль.

::: warning
Складні CAPTCHA навмисно виснажливі, і розблокування може зайняти чимало часу. Налаштовуйте з обережністю.
:::
