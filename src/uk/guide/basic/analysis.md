# {{$frontmatter.title}}

Окрім базових записів, на дашборді доступні аналітичні звіти, зокрема звіти про звички та звіти по сайтах.

## Звіт про звички

Звіт про звички складається з двох частин.

-   Звички використання сайтів. Ця частина показує контент, який ви відвідуєте найчастіше.
-   Звички за періодами доби. Ця частина показує ваші найбільш завантажені години та найдовші періоди бездіяльності.

## Звіт по сайту

Так само звіт по сайту складається з двох частин.

-   Підсумок. Ця частина показує оглядові дані для обраного сайту.
-   Тренди. Ця частина показує історичний тренд часу перегляду та кількості візитів на день для обраного сайту.
