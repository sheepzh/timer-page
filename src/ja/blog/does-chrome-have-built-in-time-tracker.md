# Chrome に内蔵の時間トラッカーはある? 代わりに使えるもの

結論から言うと: **ありません**。Chrome は訪問したサイトの一覧を見ることはできますが、各サイトに「どれだけの時間」をかけたかを教えてくれる内蔵機能は持っていません。Chrome の中でスクリーンタイムレポートに相当するものを探しているなら、小さな拡張機能が必要です。

Chrome と OS が実際に提供しているものと、その限界を見ていきます。

## Chrome が実際に提供しているもの

**履歴**: 訪問の事実と時刻は記録されますが、滞在時間は記録されません。9 時 15 分にサイトを開いたことは分かりますが、10 時 40 分までいたことは分かりません。

**Google マイアクティビティ**: Google アカウント経由で閲覧を記録しますが、これはクラウドに保存されます。スクリーンタイムツールに求めるものの正反対です。しかもサイト別の滞在時間レポートは出せません。

**設定内のパフォーマンスと使用状況**: タブごとのメモリやバッテリー消費は報告されますが、それはリソースの話であって、あなたの注意の使い方の話ではありません。

ほとんどの人が実際に知りたいこと(YouTube・Reddit・ニュースサイトに 1 日どれだけの時間を使っているか)に対して、Chrome 自体は答えを持っていません。

## OS のスクリーンタイム機能も役に立たない理由

macOS のスクリーンタイムや Windows の同等機能は、主に**アプリケーションごと**に時間を分解します。ブラウザは 1 つのアプリとして数えられるため、「Chrome: 5 時間」という表示から、どのサイトがその時間を消費したかは分かりません。プラットフォームの内蔵機能がサイト別の詳細を報告するのは、macOS の Safari といった自社ブラウザに対してだけです。Chrome・Edge・Brave・Firefox といったサードパーティブラウザは、サイトレベルでは見えません。

まさにこのギャップを、専用の拡張機能が埋めます。拡張機能はブラウザの**内側**で動き、サイトレベルのアクティビティを直接見られるからです。

## Chrome にトラッカーを追加する

<a href="/ja/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> は、Chrome に欠けている部分を追加します。

- **サイトごとの自動計測**: アクティブタブ方式で、開始も停止も不要
- **サイト別の日次・履歴レポート**: トレンドや時間帯グラフ付き([分析ガイド](/ja/guide/basic/analysis)参照)
- **ローカル保存のみ**: ブラウザ自身のストレージ API を使用。アカウント不要、クラウド不要、アップロードなし
- **Chrome・Edge・Firefox 対応**: MIT ライセンスの無料オープンソース

インストールすれば、以降はフォーカスされているサイトに秒単位の精度で時間が積み上がります。その数字に対して、同じ拡張機能内の[サイト時間制限](/ja/guide/basic/limit)で対応できるのも利点です。2 つ目のツールは不要です。

## よくある質問

**ブラウザが遅くなりませんか?** なりません。拡張機能は軽量(約 1 MB)で、どのタブにフォーカスがあるかを記録するだけで、ページの中身は検査しません。

**データはどこに保存されますか?** すべてあなたの端末のブラウザローカルストレージ内です。オープンソースのコードで確認でき、いつでも[データをエクスポートまたは同期](/ja/guide/data)できます。

**シークレット(プライベート)ウィンドウでも動きますか?** ブラウザは許可しない限りプライベートウィンドウで拡張機能を実行しないため、計測はブラウザのプライバシー設定に従います。

サイト別の滞在時間が必要なら、<a href="/ja/install" target="_blank" rel="noopener">インストールページ</a>に 3 つのブラウザのストアへのリンクがあります。
