# ウェブサイトごとの閲覧時間を記録する方法

「ちょっと見るだけ」のつもりが、気づけば1時間経っていた——そんな経験は誰にでもあります。コントロールの第一歩は測定です。ブラウザの中で時間がどこへ消えていくのか、正直に自動記録することから始めましょう。

そのためにブラウザは十分対応できます。小さな拡張機能がバックグラウンドで各サイトの滞在時間を記録すれば、手動のタイマーも推測も不要です。

この記事では、無料のオープンソース拡張機能を使って、すべてのデータを端末内にだけ保存しながら記録を始める手順を紹介します。

## なぜブラウザの履歴では足りないのか

履歴が記録するのは「訪問」であって「滞在時間」ではありません。14 時 32 分にサイトを開いたことは分かっても、1 時間滞在し続けたことは分かりません。習慣を分析するにはこの差が決定的です。

専用の時間トラッカーはアクティブなタブを追跡します。タブがフォーカスされて表示されている間だけ、そのドメインに時間が積み上がります。タブを切り替えれば時計は止まる。結果として、サイトごとの滞在時間レポートが手に入ります。

## ステップ 1: 拡張機能をインストールする

この手順では <a href="/ja/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> を使います。Chrome・Edge・Firefox に対応した無料のオープンソース拡張機能で、ワンクリックでインストールでき、登録も設定も不要です。インストールした瞬間から計測が始まります。

## ステップ 2: 時間の使い方を確認する

拡張機能のパネルを開くと、次が分かります。

- **サイト別・日別の時間**: 円グラフとランキングで表示
- **週ごとの推移**: 今週がいつもと比べてどうかを確認
- **時間帯ごとの分布**: 注意が逸れやすい時間帯が見える

ヒント: 上位 5 サイトに対して「この時間は意識して使えたか?」と自問してみてください。断片的な訪問が積み重なるサイトが、[時間制限](/ja/guide/basic/limit)の最初の候補です。

## ステップ 3: データを行動につなげる

測定はそれだけでは行動を変えませんが、どのルールが効くかを正確に示してくれます。動画サイトに毎日 90 分使っているなら、日次リミットを設定しましょう。手順は [YouTube の利用時間を制限する方法](/ja/blog/limit-time-on-youtube-websites)で解説しています。

すべてローカルに記録されるため、データはあなたのものです。いつでも [JSON や CSV にエクスポート](/ja/guide/data)でき、内蔵の [習慣レポート](/ja/guide/basic/analysis)でトレンドを確認できます。

## トラッカー選びで見るべき 4 点

1. **自動計測**: アクティブタブ方式で、手動タイマーが不要
2. **ローカル保存**: 閲覧履歴は機密データ。端末の外に出さない
3. **複数ブラウザ対応**: Chrome・Edge・Firefox を使い分けるなら必須
4. **エクスポート**: データはオープンな形式で自分のものに

Time Tracker - Web Habit Builder はこの 4 点をすべて満たします。MIT ライセンス、ブラウザのローカルストレージのみに保存、3 ブラウザ対応。他のトラッカーから乗り換える場合は、[既存データをインポート](/ja/guide/data)できます。

Chrome・Edge・Firefox のストアへのリンクは<a href="/ja/install" target="_blank" rel="noopener">インストールページ</a>にあります。
