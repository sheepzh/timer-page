# YouTube の利用時間を制限する方法

「1 本だけ見る」はずが、自動再生が次の動画を流し続けて、夜が消える。深夜 11 時の意志の力はほぼ勝てません。ブラウザが強制するルールのほうが確実です。

このガイドでは、Chrome・Edge・Firefox 対応の無料オープンソース拡張機能を使って、YouTube(または任意のサイト)に自動の時間制限を設定する手順を紹介します。

## 「YouTube 専用リミッター」拡張機能を入れない理由

ストアには単機能のリミッターがあふれています。YouTube 用、TikTok 用、Instagram 用と、サイトごとに別々の拡張機能を入れる方式です。

- **1 サイト 1 拡張機能**では、5 サイトで 5 つのツール、5 組の権限要求になる
- ほとんどは対象の 1 サイトしか分からない。ニュースや Reddit の習慣は守備範囲外
- 拡張機能が増えるほどメモリを消費し、ブラウザが信頼する相手も増える

汎用のルールエンジンなら 1 つのツールで済みます。[時間を記録する](/ja/blog/how-to-track-time-spent-on-websites)のと同じ拡張機能が、任意の URL パターンに制限を適用できます。

## 制限ルールの仕組み

<a href="/ja/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> では、各ルールは対象 URL と 1 つ以上の制約を組み合わせます(完全な解説は[コントロールガイド](/ja/guide/basic/limit))。

| 制約 | 動作 |
| --- | --- |
| **日次上限** | サイトごとの 1 日の上限。予算を使い切ると翌日までブロック用のマスクが被さる |
| **訪問ごとの上限** | 1 回の訪問に上限を設定。「ちょっと確認」が 1 時間になるのを防ぐ |
| **禁止時間帯** | 設定した時間帯はサイトにアクセスできない。例: 平日の 9:00–12:00 |
| **週次上限** | 日次上限が合わないパターン向けの 1 週間の上限 |
| **集中セッション** | 集中(Pomodoro)セッション中は制限対象サイトがブロックされ続ける |

URL はパターン式に対応しているので、1 つのルールでドメイン全体も特定のセクションもカバーできます。

## YouTube の制限を設定する手順

1. ストアから拡張機能をインストール。無料でアカウント不要
2. ダッシュボードを開き、コントロール(制限)セクションへ
3. 制限 URL に `https://www.youtube.com` を指定してルールを作成
4. 日次上限を設定——例えば 30 分
5. 必要なら訪問ごとに 10 分の上限と、集中したい時間帯の「禁止時間帯」を追加

以降、日次の予算を使い切るとページにブロック用のマスクが被さり、翌日まで(または意図的にルールを変更するまで)ブロックが続きます。ロック解除の確認(質問・パスワード・二要素認証)を設定しておけば、回避がワンクリックではなく意図的な行為になります。

## 同じルールの使い回しが効く

ルールエンジンは URL パターンで判定するため、SNS・ニュース・ショッピング・ゲームも同じ方法で制限できます。Chrome・Edge・Firefox で動作するので、ルールは使っているすべてのブラウザをカバーします。

実用的な初期セットの例:

- **SNS のフィード**: 1 日 20 分+勤務時間帯は禁止
- **ニュース**: 訪問ごとの上限のみ。確認は短く保つ
- **動画ストリーミング**: 夜の視たい時間帯に日次上限

すべてのデータ(ルールも利用履歴も)はブラウザ内のローカルに保存されます。いつでも[エクスポート](/ja/guide/data)でき、制限の詳細は[コントロールガイド](/ja/guide/basic/limit)で確認できます。

まずは時間を最も取られている 1 サイトのルールから始めれば十分です。ストアへのリンクは<a href="/ja/install" target="_blank" rel="noopener">インストールページ</a>にあります。
