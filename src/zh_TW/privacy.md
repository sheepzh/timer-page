# {{$frontmatter.title}}

::: info
為了提供你完整的服務，本擴充功能僅會在使用過程中收集必要範圍內的個人資料，詳情請見以下隱私權聲明。
:::

## 哪些資料會被收集？

| 內容           | 用途                                                   | 是否必需                             |
| -------------- | ------------------------------------------------------ | ------------------------------------ |
| 網站訪問記錄   | 用於統計瀏覽時間和訪問次數                             | 是                                   |
| 瀏覽器分頁資訊 | 用於自動取得網站的名稱和圖示，展示資料時提升使用者體驗 | 只有在選項開啟自動取得功能後才會收集 |

## 如何處理這些資料？

我們保證該擴充功能收集的所有資料只會保存在你的瀏覽器本地儲存中，絕不會將它傳送到其他地方。

不過你可以使用擴充功能提供的工具，以 JSON 或 CSV 的檔案格式，匯出或匯入你的資料。本擴充功能也支援你使用 GitHub Gist 等你足以信任的第三方服務來備份資料。

::: tip
我們只協助你收集資料，資料完全由你掌控。
:::
