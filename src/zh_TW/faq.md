# {{$frontmatter.title}}

關於 Time Tracker 如何處理你的資料、支援哪些瀏覽器，以及如何掌控瀏覽時間的快速解答。設定步驟請見[入門指南](/zh_TW/guide/start)。

## Time Tracker 會收集我的瀏覽資料嗎？

不會。所有資料都透過 `chrome.storage.local` API 儲存在你的瀏覽器本機，從不傳送到任何伺服器。專案完全開放原始碼，可以在程式碼中自行驗證。

## 支援哪些瀏覽器？

桌面版的 Chrome、Edge 與 Firefox，以及 Android 版 Firefox（包含網站封鎖）。Android 版 Chrome 不支援擴充功能。

## Time Tracker 是免費的嗎？

是。擴充功能完全免費且開放原始碼，沒有帳號，也沒有訂閱。

## 可以跨裝置同步資料嗎？

可以，透過你自行掌控的服務。資料可匯出為 JSON 或 CSV 檔案再到另一部裝置匯入，或備份到你自己的 WebDAV 伺服器、GitHub Gist 或 Obsidian——手動執行，或依你設定的排程自動執行。過程中不涉及我們的第三方雲端。詳情見[資料同步](/zh_TW/guide/data)。

## 如何限制在分心網站上花費的時間？

建立一條含受限 URL 的規則，然後設定每日或每週上限、單次造訪上限，或不允許存取的時段。達到上限時規則立即生效。完整流程見[限制網站使用時間](/zh_TW/guide/basic/limit)。

## 切換分頁或播放影片時還會計時嗎？

計時器跟隨取得焦點的分頁。全螢幕影片一律視為使用中，播放聲音的分頁也視為使用中。其餘情況下，切離分頁時計時即停止，偵測不到活動時也可能自動暫停。

## 在行動瀏覽器上可以使用嗎？

支援 Android 版 Firefox，包含追蹤與網站封鎖。行動版 Chrome 與 iOS 瀏覽器不支援所需的擴充功能 API，因此無法涵蓋這些平台。

## 我的資料會保存多久？

依設計是無期限。資料會留在你的裝置上，直到你在資料管理頁面自行刪除，沒有自動的保存期限。

## 可以從其他時間追蹤擴充功能遷移資料嗎？

可以。支援匯入 Webtime Tracker（CSV 或 JSON）、Web Activity Time Tracker（CSV）與 History Trends Unlimited（TSC）匯出的資料，並可選擇覆蓋或附加到本機資料。參見[資料同步](/zh_TW/guide/data)。

## 我的使用統計會被回報到任何地方嗎？

不會。擴充功能沒有遙測、沒有分析、沒有遠端日誌。你瀏覽了什麼、瀏覽了多久，都留在你的裝置上。
