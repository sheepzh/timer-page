## Какие данные собираются?

| Содержание                   | Использование                                                                                                                     | Обязательно                                   |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| История просмотра веб-сайтов | Используется для подсчета времени просмотра и посещений                                                                           | Да                                            |
| Информация о вкладках        | Используется для автоматического получения названия и значка веб-сайта и улучшения пользовательского опыта при отображении данных | Только если эта функция включена в настройках |

## Что делается с этими данными?

Мы гарантируем, что все данные, собранные этим расширением, будут сохраняться только в локальном хранилище вашего браузера и никогда не будут передаваться куда-либо еще.

Однако вы можете использовать инструменты, предоставляемые расширением, для экспорта или импорта ваших данных в формате файлов JSON или CSV. Расширение также поддерживает использование GitHub Gist и других сторонних сервисов, которым вы доверяете, для резервного копирования ваших данных.

::: tip
Мы только помогаем вам собирать данные. Полный контроль остаётся за вами.
:::
