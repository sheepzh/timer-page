# Есть ли в Chrome встроенный трекер времени? Что использовать вместо него

Короткий ответ: **нет**. Chrome показывает список посещённых сайтов, но не показывает, *сколько времени* вы провели на каждом из них. Для отчёта по экранному времени внутри Chrome нужно небольшое расширение.

Ниже — полная картина, включая объяснение, почему функции «экранного времени» вашей системы браузер не покрывают.

## Что на самом деле есть в Chrome

**История**: фиксирует сам факт визита и время открытия, но не длительность. Видно, что сайт открыт в 9:15, но не видно, что вы не уходили до 10:40.

**Мои действия (Google)**: записывает посещения через аккаунт Google и хранит их в облаке, то есть противоположность тому, чего ждут от трекера экранного времени. Отчёта с длительностью по сайтам там тоже нет.

**Статистика в настройках**: Chrome показывает потребление памяти и заряда по вкладкам; это про ресурсы, а не про ваше внимание.

На вопрос, который реально задают люди — «сколько времени я провожу на YouTube, Reddit или новостных сайтах в день?» — сам Chrome ответа не даёт.

## Почему «экранное время» операционной системы не помогает

Экранное время в macOS и аналогичные функции в Windows разбивают время в основном **по приложениям**. Браузер — это одно приложение: «Chrome: 5 часов» не говорит, какие сайты забрали эти часы. Детализацию по сайтам платформы обычно дают только для собственных браузеров, например Safari в macOS. Сторонние браузеры (Chrome, Edge, Brave, Firefox) на уровне сайтов остаются невидимыми.

Именно эту брешь закрывает расширение: оно живёт *внутри* браузера и видит активность на уровне сайтов напрямую.

## Open-source трекер для Chrome

<a href="/ru/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> добавляет то, чего не хватает Chrome:

- **Автоматический учёт времени по сайтам** по активной вкладке: без таймеров
- **Отчёты по дням и истории** по каждому сайту, с трендами и распределением по времени суток (см. [руководство по анализу](/ru/guide/basic/analysis))
- **Только локальное хранение** в собственном хранилище браузера: без аккаунта, без облака, без отправки данных
- **Для Chrome, Edge и Firefox**, бесплатно и с открытым кодом под лицензией MIT

После установки часы идут для каждого сайта в фокусе, с точностью до секунды. На основе цифр можно сразу настроить [ограничения времени](/ru/guide/basic/limit) в том же расширении.

## Частые вопросы

**Это замедляет браузер?** Нет. Расширение лёгкое (около 1 МБ) и запоминает только активную вкладку; содержимое страниц не анализируется.

**Где хранятся данные?** Только в локальном хранилище браузера на вашем устройстве. Это проверяется по открытому коду, а данные можно в любой момент [экспортировать или синхронизировать самостоятельно](/ru/guide/data).

**Работает ли это в приватных окнах?** Браузеры не запускают расширения в приватных окнах без явного разрешения; учёт следует правилам приватности вашего браузера.
