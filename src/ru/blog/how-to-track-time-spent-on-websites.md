# Как узнать, сколько времени вы проводите на сайтах

Хотели заглянуть «на минутку» — и через час не понимаете, куда ушло время. Первый шаг к контролю — измерение: честная автоматическая запись того, куда уходит время в браузере.

Браузер умеет это делать: небольшое расширение записывает время на каждом сайте в фоне, без ручных таймеров и без догадок.

Инструкция ниже показывает настройку шаг за шагом и использует бесплатный open-source трекер, который хранит все данные только на вашем устройстве.

## Почему не подходит история браузера?

История хранит *визиты*, а не *длительность*. Видно, что вы открыли сайт в 14:32, но не видно, что остались на час. Для анализа привычек этого недостаточно.

Специальный трекер времени следит за активной вкладкой: пока вкладка в фокусе и видима, время накапливается на этот домен. Переключились — часы остановились. Результат — отчёт с длительностью по каждому сайту.

## Шаг 1: установите расширение

В этой инструкции используется <a href="/ru/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a>, бесплатное расширение с открытым кодом для Chrome, Edge и Firefox. Установка в один клик: учёт начинается сразу, без регистрации и настройки.

С первой минуты каждый сайт в фокусе фиксируется с точностью до секунды.

## Шаг 2: посмотрите, куда уходит время

Откройте панель расширения. Вы увидите:

- **Время по сайтам и дням**: в виде диаграмм и рейтингов
- **Динамику по неделям**, чтобы сравнить эту неделю с обычной
- **Распределение по времени суток**: когда внимание обычно «уплывает»

Совет: посмотрите на топ-5 сайтов и задайте к каждому один вопрос: «это время было осознанным?» Сайты с длинным хвостом случайных визитов — первые кандидаты на [ограничения времени](/ru/guide/basic/limit).

## Шаг 3: превратите данные в действия

Само измерение поведение не меняет, но точно показывает, где поможет правило. Отчёт показывает 90 минут в день на видеосайтах? Установите дневной лимит. Пошагово это описано в статье [Как ограничить время на YouTube](/ru/blog/limit-time-on-youtube-websites).

Поскольку всё записывается локально, цифры принадлежат вам: данные можно в любой момент [экспортировать в JSON или CSV](/ru/guide/data), а встроенные [отчёты о привычках](/ru/guide/basic/analysis) показывают тренды.

## На что смотреть при выборе трекера

1. **Автоматический учёт**: по активной вкладке, без ручных таймеров
2. **Локальное хранение**: история посещений чувствительна; ей место на вашем устройстве
3. **Несколько браузеров**: Chrome, Edge и Firefox, если вы пользуетесь более чем одним
4. **Экспорт**: ваши данные принадлежат вам, в открытом формате

Time Tracker - Web Habit Builder соответствует всем четырём пунктам: лицензия MIT, хранение только в локальном хранилище браузера, поддержка всех трёх браузеров. Если вы переходите с другого трекера, [существующие данные можно импортировать](/ru/guide/data).

На этом настройка закончена. Ссылки на магазины для Chrome, Edge и Firefox есть на странице <a href="/ru/install" target="_blank" rel="noopener">установки</a>.
