# Аналоги Webtime Tracker: бесплатные open-source трекеры для нескольких браузеров

Webtime Tracker — известное расширение Chrome, которое показывает, сколько времени вы проводите на сайтах. Оно просто делает одну задачу, и многим это нравится. Но если вы ищете альтернативу — из-за функций, другого браузера или гарантий приватности — есть несколько вариантов, о которых стоит знать.

Ниже — сравнение на основе публичных описаний из магазинов, а затем рекомендации, как выбрать подходящий инструмент.

## Кратко

| Инструмент | Браузеры | Блокировка/лимиты | Хранение данных | Бесплатно |
| --- | --- | --- | --- | --- |
| Time Tracker - Web Habit Builder | Chrome, Edge, Firefox | Да: дневные, на визит, временные окна | Только локально | Да, open source |
| Web Activity Time Tracker | Chrome | Да, плюс Pomodoro | Локально | Да |
| StayFocusd | Chrome | Да: ограничение времени | Локально | Да |
| ActivityWatch | Десктоп-приложение + расширения | Нет (фокус на учёте и анализе) | Локально | Да, open source |
| Webtime Tracker | Chrome | Нет: фокус на учёте и статистике | Локально | Да |

Заметки о функциях основаны на публичных описания самих инструментов; актуальные детали проверяйте в карточках магазинов.

## 1. Time Tracker - Web Habit Builder: ближайшая замена «всё в одном»

<a href="/ru/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> покрывает ядро Webtime Tracker (автоматическая статистика времени по сайтам) и добавляет то, что иначе пришлось бы ставить отдельными расширениями:

- **Полная аналитика**: отчёты по дням и истории по каждому сайту, тренды по неделям, распределение по времени суток (см. [руководство по анализу](/ru/guide/basic/analysis))
- **Действенные лимиты**: дневные лимиты, ограничения на визит и «запрещённые» периоды для любого URL-шаблона ([как это работает](/ru/blog/limit-time-on-youtube-websites))
- **Три браузера вместо одного**: Chrome, Edge и Firefox — важно, если вы переключаетесь между рабочим и личным браузером
- **Только локально и открытый код**: лицензия MIT, всё хранится в локальном хранилище браузера, ни одной учётной записи
- **Прямой импорт из Webtime Tracker**: историю можно перенести с собой, см. ниже

Это более функциональный инструмент, поэтому дашборд объёмнее минималистичного вида Webtime Tracker. Если вам нужен только один круговой график, Webtime Tracker по-прежнему хороший выбор.

## 2. Web Activity Time Tracker: похожий набор, но только Chrome

Web Activity Time Tracker также совмещает учёт с блокировкой сайтов и добавляет таймер Pomodoro. Если вы работаете только в Chrome и хотите немного другой интерфейс, это разумный кандидат. Firefox и Edge не поддерживаются, поэтому проблема нескольких браузеров им не решается.

## 3. StayFocusd: ветеран ограничений

StayFocusd существует много лет и делает ставку на ограничение времени на отвлекающих сайтах, а не на глубокую аналитику. Только Chrome, отчёты базовые. Выбирайте, если цель — только ограничения; пропустите, если нужна ещё и измерительная часть (придётся ставить второе расширение).

## 4. ActivityWatch: open source за пределами браузера

ActivityWatch — отличный open-source трекер, который работает как десктоп-приложение и следит за приложениями и сайтами на уровне всей системы, полностью локально. Выбирайте его, если нужен учёт шире браузера. Если же вас интересуют именно привычки в браузере, чистое расширение проще в установке и обслуживании: без фонового приложения и одинаково на любой ОС.

## Что выбрать?

- **Хочу учёт + анализ + лимиты в одном бесплатном инструменте и в Chrome/Edge/Firefox** → Time Tracker - Web Habit Builder
- **Нужно решение уровня всей системы и open source** → ActivityWatch
- **Нужна только простая статистика** → текущий Webtime Tracker подойдёт

## Как перейти без потери истории

Time Tracker включает инструмент импорта, который читает экспорт из **Webtime Tracker** (CSV или JSON), **Web Activity Time Tracker** (CSV) и **History Trends Unlimited** (TSC). Экспортируйте данные из текущего расширения, импортируйте — историческая статистика переносится. Точные шаги — в статье [Синхронизация данных](/ru/guide/data).

Ссылки на магазины есть на странице <a href="/ru/install" target="_blank" rel="noopener">установки</a>: сначала экспорт из Webtime Tracker, остальное сделает инструмент импорта.
