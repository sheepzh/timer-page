# Как ограничить время на YouTube и других сайтах

«Посмотрю одно видео» — и вечер исчез в автопроигрывании: очередь сама подкладывает следующее видео, а сила воли в одиннадцать вечера обычно проигрывает. Правило, которое принуждает сам браузер, держится лучше.

Инструкция ниже показывает, как настроить реальный автоматический лимит для YouTube (или любого сайта) с помощью бесплатного open-source расширения для Chrome, Edge и Firefox.

## Почему не «расширение для YouTube»?

В магазине полно узких лимитеров: один для YouTube, другой для TikTok, третий для Instagram. Проблемы накапливаются:

- **Одно расширение на сайт**: пять сайтов, пять инструментов, пять наборов разрешений
- Большинство знает только один целевой сайт; привычка к новостям или Reddit остаётся вне охвата
- Каждое лишнее расширение — это память и ещё одна сторона, которой браузер должен доверять

Универсальный движок правил закрывает всё одним инструментом: то же расширение, которое [учитывает ваше время](/ru/blog/how-to-track-time-spent-on-websites), применяет лимиты к любому URL-шаблону.

## Как работают правила ограничений

В <a href="/ru/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> каждое правило сочетает целевой URL с одним или несколькими условиями (полное руководство: [контроль](/ru/guide/basic/limit)):

| Условие | Действие |
| --- | --- |
| **Дневной лимит** | Максимум времени в день на сайт; когда бюджет исчерпан, страница закрывается блокирующей маской до следующего дня |
| **Лимит на визит** | Ограничивает каждый отдельный визит, чтобы «быстро глянуть» не превратилось в час |
| **Запрещённые периоды** | Блокирует сайт в заданные окна, например 9:00–12:00 в рабочие дни |
| **Недельный лимит** | Максимум времени в неделю, когда дневной лимит не подходит |
| **Сессии фокуса** | Во время сессии фокуса/помодоро ограниченные сайты остаются заблокированными |

URL поддерживают шаблоны: одно правило может покрыть весь домен или отдельные его разделы.

## Лимит на YouTube, шаг за шагом

1. Установите расширение из магазина, бесплатно и без аккаунта
2. Откройте панель и перейдите в раздел контроля
3. Создайте правило с `https://www.youtube.com` в качестве целевого URL
4. Установите дневной лимит, например 30 минут
5. Опционально: лимит 10 минут на визит и «запрещённые» часы для времени глубокой работы

Теперь, когда дневной бюджет исчерпан, страницу закрывает блокирующая маска, и она остаётся до следующего дня, если вы намеренно не измените правило. Опциональная верификация при разблокировке (пароль, вопрос или двухфакторная аутентификация) превращает обход правила в осознанное действие, а не в нажатие одной кнопки.

## То же правило работает для всего остального

Движок правил использует шаблоны URL, а не жёсткий список сайтов: тот же подход ограничивает соцсети, новости, шопинг или игры. Расширение работает в Chrome, Edge и Firefox, так что правила покрывают все браузеры, которыми вы пользуетесь.

Практичный стартовый набор:

- **Соцсети**: 20 минут в день плюс запрещённые часы в рабочее время
- **Новости**: только лимит на визит, чтобы быстрые проверки оставались быстрыми
- **Стриминг**: дневной лимит на вечер, когда вы действительно хотите смотреть

Все данные, правила и история использования, остаются локально в браузере и в любой момент экспортируются ([передача данных](/ru/guide/data)).

Начните с одного правила для сайта, который отнимает больше всего времени; остальное подождёт. Ссылки на магазины есть на странице <a href="/ru/install" target="_blank" rel="noopener">установки</a>.
