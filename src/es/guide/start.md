# {{$frontmatter.title}}

Puedes comenzar rápidamente a usar esta extensión en solo 3 sencillos pasos.

## 1. Fijar el icono

En primer lugar, para usar esta extensión de manera más conveniente, te recomendamos anclarla. Esto funciona de forma distinta en cada navegador; la siguiente figura muestra cómo hacerlo en Chrome.

<div style="display: flex; justify-content: center;">
    <img src="/images/pin.png" width=400 />
</div>

## 2. Navegar por cualquier sitio web

Luego, navega por cualquier sitio web, y verás que el tiempo avanza en el icono, así <img src="/images/beating.gif" style="display: inline-block;height: 24px;"/>.

## 3. Ver datos en la página emergente

Finalmente, haz clic en el icono para abrir la página emergente, donde podrás ver los datos de hoy, esta semana o este mes en un gráfico circular.

Y puedes acceder a todas las funciones haciendo clic en el enlace en la parte inferior de esta página.

::: tip
¡Has aprendido el uso básico, pruébalo!
:::
