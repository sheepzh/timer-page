# Webtime Tracker Alternativen: kostenlos, quelloffen und browserübergreifend

Webtime Tracker ist eine bekannte Chrome-Erweiterung, um zu sehen, wie viel Zeit du auf Websites verbringst. Sie macht eine Aufgabe einfach, und vielen reicht das. Je nachdem, warum du eine Alternative suchst — mehr Funktionen, ein anderer Browser oder andere Datenschutzgarantien —, gibt es mehrere Optionen, die du kennen solltest.

Unten ein Vergleich anhand der öffentlichen Store-Beschreibungen, danach eine Einordnung, welches Tool zu welcher Situation passt.

## Auf einen Blick

| Tool | Browser | Blockierung/Limits | Datenspeicherung | Kostenlos |
| --- | --- | --- | --- | --- |
| Time Tracker - Web Habit Builder | Chrome, Edge, Firefox | Ja: täglich, pro Besuch, Zeitfenster | Nur lokal | Ja, Open Source |
| Web Activity Time Tracker | Chrome | Ja, plus Pomodoro | Lokal | Ja |
| StayFocusd | Chrome | Ja: Zeitbeschränkung | Lokal | Ja |
| ActivityWatch | Desktop-App + Erweiterungen | Nein (Fokus auf Tracking/Analyse) | Lokal | Ja, Open Source |
| Webtime Tracker | Chrome | Nein: Fokus auf Tracking/Statistik | Lokal | Ja |

Die Funktionshinweise basieren auf den öffentlichen Beschreibungen der Tools; aktuelle Details prüfe bitte in den jeweiligen Store-Einträgen.

## 1. Time Tracker - Web Habit Builder: der nächstliegende All-in-One-Ersatz

<a href="/de/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a> deckt den Kern von Webtime Tracker ab (automatische Zeitstatistik pro Website) und ergänzt, was du sonst separat installieren müsstest:

- **Volle Tracking-Analytik**: tägliche und historische Berichte pro Website, Wochenverläufe und Tageszeit-Verteilung (siehe [Analyse-Guide](/de/guide/basic/analysis))
- **Wirksame Limits**: Tageslimits, Limits pro Besuch und „nicht erlaubt"-Zeitfenster für jedes URL-Muster ([so funktioniert es](/de/blog/limit-time-on-youtube-websites))
- **Drei Browser statt einem**: Chrome, Edge und Firefox — wichtig, wenn du zwischen Arbeits- und Privatbrowser wechselst
- **Nur lokal und quelloffen**: MIT-lizenziert, alles liegt im lokalen Speicher deines Browsers, null Konten
- **Direkter Import aus Webtime Tracker**: deine Historie kommt mit, siehe unten

Es ist das reichhaltigere Tool, deshalb hat das Dashboard mehr Oberfläche als Webtime Trackers Minimalansicht. Wenn du nur ein einziges Kreisdiagramm willst, bleibt Webtime Tracker eine gute Wahl.

## 2. Web Activity Time Tracker: ähnlicher Umfang, nur Chrome

Web Activity Time Tracker kombiniert ebenfalls Tracking mit Site-Blockierung und ergänzt einen Pomodoro-Timer. Wenn du mit Chrome zufrieden bist und eine etwas andere Oberfläche möchtest, ist es ein vernünftiger Kandidat. Firefox und Edge werden nicht unterstützt, das Mehr-Browser-Problem löst es also nicht.

## 3. StayFocusd: der Veteran für Beschränkung

StayFocusd gibt es seit vielen Jahren und setzt auf das Begrenzen von Zeit auf ablenkenden Websites statt auf tiefe Analytik. Nur Chrome, die Tracking-Berichte sind grundlegend. Wähle es, wenn Beschränkung dein einziges Ziel ist; überspringe es, wenn du auch die Messseite willst (dann bräuchtest du eine zweite Erweiterung).

## 4. ActivityWatch: Open Source jenseits des Browsers

ActivityWatch ist ein ausgezeichneter Open-Source-Tracker, der als Desktop-Anwendung läuft und Apps und Websites systemweit und vollständig lokal überwacht. Nimm es, wenn dein Tracking über den Browser hinausgehen soll. Geht es dir vor allem um Surfgewohnheiten, ist eine reine Erweiterung leichter zu installieren und zu pflegen: keine Hintergrund-App, und sie funktioniert auf jedem Betriebssystem gleich.

## Was solltest du wählen?

- **Track + Analyse + Limits in einem kostenlosen Tool, über Chrome/Edge/Firefox hinweg** → Time Tracker - Web Habit Builder
- **Eine systemweite, quelloffene Lösung** → ActivityWatch
- **Nur einfache Statistik, sonst nichts** → dein jetziger Webtime Tracker reicht

## Umstieg ohne Verlust der Historie

Time Tracker enthält ein Import-Tool, das Exporte von **Webtime Tracker** (CSV oder JSON), **Web Activity Time Tracker** (CSV) und **History Trends Unlimited** (TSC) liest. Aus der aktuellen Erweiterung exportieren, importieren — die historische Statistik wird übernommen. Die genauen Schritte stehen in [Datenübertragung](/de/guide/data).

Die Store-Links findest du auf der <a href="/de/install" target="_blank" rel="noopener">Installationsseite</a>; zuerst aus Webtime Tracker exportieren, den Rest übernimmt das Import-Tool.
