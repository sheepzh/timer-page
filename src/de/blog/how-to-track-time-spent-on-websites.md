# Zeit auf Websites messen in Chrome, Edge und Firefox

Du willst eigentlich nur kurz etwas nachsehen, und eine Stunde später fragst du dich, wo die Zeit geblieben ist. Der erste Schritt zurück zur Kontrolle ist die Messung: ein vollständiger, automatischer Datensatz darüber, wohin deine Browserzeit wirklich fließt.

Dein Browser kann genau das: Eine kleine Erweiterung zeichnet die Zeit auf jeder Website im Hintergrund auf. Keine manuellen Timer, kein Tagebuch, kein Rätselraten.

Diese Anleitung zeigt die Einrichtung Schritt für Schritt, mit einem kostenlosen Open-Source-Tracker, der alle Daten auf deinem eigenen Gerät behält.

## Warum nicht einfach den Browserverlauf?

Der Verlauf speichert *Besuche*, keine *Dauer*. Du siehst, dass du eine Nachrichtenseite um 14:32 geöffnet hast, aber nicht, dass du eine Stunde geblieben bist. Für Gewohnheitsanalyse taugt das nicht.

Ein dedizierter Zeit-Tracker beobachtet stattdessen den aktiven Tab: Solange ein Tab fokussiert und sichtbar ist, läuft die Zeit für diese Domain. Beim Wechsel stoppt die Uhr. Das Ergebnis ist ein Bericht mit Dauer pro Website: genau die Zahl, die du willst.

## Schritt 1: Erweiterung installieren

In dieser Anleitung verwenden wir <a href="/de/install" target="_blank" rel="noopener">Time Tracker - Web Habit Builder</a>, eine kostenlose Open-Source-Erweiterung für Chrome, Edge und Firefox. Ein Klick im Store genügt. Die Aufzeichnung beginnt sofort, ohne Konto und ohne Konfiguration.

Ab der ersten Minute wird jede fokussierte Website sekundengenau erfasst.

## Schritt 2: Wohin geht die Zeit?

Öffne das Dashboard der Erweiterung. Du siehst:

- **Zeit pro Website und Tag**, als Diagramme und Ranglisten
- **Verlauf über Wochen**, um diese Woche mit deinem Normalzustand zu vergleichen
- **Verteilung über die Tageszeit**, die zeigt, wann deine Aufmerksamkeit typischerweise abdriftet

Ein Tipp: Sieh dir deine Top-fünf-Websites an und stelle zu jeder eine Frage: „War diese Zeit beabsichtigt?" Domains mit vielen unbeabsichtigten Besuchen sind die ersten Kandidaten für [Zeitlimits](/de/guide/basic/limit).

## Schritt 3: Aus Daten Maßnahmen ableiten

Messung allein ändert kein Verhalten, zeigt aber genau, wo eine Regel hilft. Zeigt der Bericht 90 Minuten täglich auf Videoseiten, setze dort ein Tageslimit. Die Anleitung dazu: [Zeit auf YouTube begrenzen](/de/blog/limit-time-on-youtube-websites).

Weil alles lokal aufgezeichnet wird, gehören dir die Zahlen. Du kannst die Daten jederzeit [als JSON oder CSV exportieren](/de/guide/data) oder mit den eingebauten [Gewohnheitsberichten](/de/guide/basic/analysis) Trends auswerten.

## Worauf du bei einem Zeit-Tracker achten solltest

Unabhängig vom Tool, prüfe vier Dinge:

1. **Automatische Aufzeichnung**: aktiver Tab, keine vergessbaren manuellen Timer
2. **Lokale Speicherung**: dein Surfverhalten ist sensibel; es gehört auf dein Gerät
3. **Mehrere Browser**: Chrome, Edge und Firefox, falls du mehr als einen nutzt
4. **Exportierbarkeit**: deine Daten gehören dir, in einem offenen Format

Time Tracker - Web Habit Builder erfüllt alle vier: MIT-lizenziert, ausschließlich lokale Speicherung im Browser, und auf allen drei großen Browsern verfügbar. Wer von einem anderen Tracker kommt, kann sogar [bestehende Daten importieren](/de/guide/data) statt bei null anzufangen.

Das war die ganze Einrichtung. Auf der <a href="/de/install" target="_blank" rel="noopener">Installationsseite</a> findest du die Store-Links für Chrome, Edge und Firefox.
